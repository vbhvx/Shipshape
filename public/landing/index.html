Builds run in a locked container

Generated code never runs on the Shipshape server. Each app is installed, built and started inside Docker, as a user without root.

  • All Linux capabilities dropped
  • 2 GB of memory, 2 CPUs, 100 processes
  • Ports open on localhost only

Questions

About the code you get, the model and the limits.

See what it builds

What does Shipshape generate?

A Next.js App Router project in TypeScript, styled with Tailwind CSS: pages, components, storage and a package.json.

Do I own the code?

Yes. Export any version as a zip and use it however you like. Nothing in the export calls back to Shipshape.

Which AI model writes the code?

Google Gemini when a key is set. Without one, a template engine writes the app, so Shipshape runs with no AI key at all.

What happens when a build fails?

Shipshape reads the failed checks, patches the files and builds again. After 3 attempts it stops and shows you the errors and the log.

What does it cost?

Nothing during the public beta. Each account can start 20 generations an hour.

What can it not build?

Anything that is not a Next.js app. A run also has 60 seconds, so very large apps are out of reach for now.
